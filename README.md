# ❌⭕ Tic-Tac-Toe

A simple browser-based Tic-Tac-Toe game built with vanilla JavaScript. This project focuses on implementing core game logic, handling user interactions, and updating the UI dynamically.

---

## 🚀 Features

* 🎮 Two-player gameplay (Player X vs Player O)
* 🔄 Turn-based system
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🔁 Restart game functionality
* ⚡ Real-time UI updates

---

## 🧱 Tech Stack

* **HTML** – structure
* **CSS** – styling
* **JavaScript** – game logic & interactivity

## 🎮 How to Play

1. Open the game in your browser
2. Player **X** starts first
3. Players take turns clicking on empty cells
4. First player to get 3 in a row (horizontal, vertical, diagonal) wins
5. If all cells are filled without a winner — it's a draw
6. Restart the game to play again
